Gute Gedanken brauchen Raum

Diese Referenz zeigt die gemeinsame Typografie für Artikel und längere Texte: Überschriften, Absätze, Listen und kleine Auszeichnungen. Die Textspalte wird durch das zwölfspaltige Grid dieser Seite festgelegt. Das Prose-Modul selbst definiert keine Breite.

Ein zweiter Absatz führt den Gedanken fort. Sein Abstand ist kleiner als die Unterbrechung vor einem neuen Abschnitt. So entstehen erkennbare Beziehungen, ohne dass jede Textzeile an einem festen Grundlinienraster ausgerichtet wird. Auch auf schmalen Bildschirmen bleibt die Schrift gleich groß; die Spalte nimmt dort die verfügbare Breite ein.

Ein neuer Gedankengang

Vor einer Zwischenüberschrift liegt mehr Raum als zwischen zwei Absätzen. Die Überschrift gehört dadurch sichtbar zum folgenden Text. Eine wichtige Aussage lässt sich hervorheben; eine Betonung kann leiser ausfallen. Ein Link zum Abschnitt über Listen bleibt im Lesetext gut erkennbar.

Ein längerer Absatz hilft dabei, Zeilenhöhe und Lesefluss zu beurteilen. Wer einen philosophischen Text liest, folgt häufig mehreren Schritten: einer Frage, einer Unterscheidung und schließlich einem Einwand. Die Gestaltung soll diesen Weg unterstützen. Sie gibt dem Text Ruhe und lässt zugleich genug Raum für unterschiedliche Inhalte und eine eigene visuelle Komposition.

Eine nähere Unterscheidung

Die dritte Überschriftenebene gliedert innerhalb eines Abschnitts. Sie ist etwas größer und kräftiger als der Lesetext, bleibt ihm aber näher als die zweite Ebene. Ein manueller Zeilenumbruch kann sinnvoll sein:
etwa wenn zwei kurze Zeilen inhaltlich zusammengehören.

Dieser kurze Absatz zeigt den normalen Anschluss nach dem Unterabschnitt.

Direkt aufeinanderfolgende Überschriften

Wenn kein Absatz zwischen zwei Überschriften steht, bleibt ihr Abstand kompakt. Der größere Abschnittsabstand wird dadurch nicht zweimal hintereinander eingesetzt.

Gedanken als Liste ordnen

Eine ungeordnete Liste sammelt zusammengehörige Gesichtspunkte:

  • Eine kurze Beobachtung.
  • Ein ausführlicherer Punkt, der über mehrere Zeilen laufen kann und zeigt, wie sich die Einrückung zum Zeilenabstand des übrigen Textes verhält.
  • Ein Gedanke mit Unterpunkten:
    • Eine erste Präzisierung.
    • Eine zweite Präzisierung, die den Zusammenhang ergänzt.

Nach der Liste setzt der Text mit dem normalen Absatzabstand wieder ein. Für eine Abfolge eignet sich eine geordnete Liste:

  1. Die Ausgangsfrage formulieren.

  2. Eine mögliche Antwort untersuchen.

    Dieser Listenpunkt enthält einen zweiten Absatz. Innerhalb des Punktes ist der Abstand kleiner als zwischen eigenständigen Absätzen.

  3. Den Einwand prüfen und die Frage neu stellen.

Begriffe und Erläuterungen

Rhythmus
Die Wiederkehr vertrauter Abstände und typografischer Rollen.
Kontext
Der Zusammenhang, in dem ein Text oder Gestaltungselement seine Aufgabe erfüllt.

Kleine Auszeichnungen im Text

Auch technische Begriffe wie class="prose" können im Lesetext stehen. Eine Tastenkombination wie Cmd + +, eine Abkürzung wie z. B. oder eine Formel wie x2 brauchen keine eigene Abstandsskala.

<main class="container grid">
    <section class="cols prose"
        style="--col-start: 3; --col-end: -3;">
        <h1>Ein Titel</h1>
        <p>Ein Absatz.</p>
    </section>
</main>

Codeblöcke können bei Bedarf horizontal scrollen. Der folgende Trenner markiert eine stärkere gedankliche Unterbrechung.
